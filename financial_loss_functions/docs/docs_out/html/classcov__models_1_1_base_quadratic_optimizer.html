Detailed Description

Shared quadratic-solver utilities.

Solves problems of the form: minimize 0.5 x^T P x + q^T x s.t. A x = b (equality) G x <= h (inequality) bounds on x (optional)

regfloat | 'auto' small ridge added to diagonal of covariance to stabilize inversion.
  • If float >= 0: used as ridge added to diagonal of P.
  • If 'auto': ridge = eps * trace(P)/n where eps = 1e-8 (safe default).
